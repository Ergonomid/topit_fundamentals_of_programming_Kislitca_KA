### Ошибка изменяемого значения по умолчанию

**Прогноз:** выражение [] в сигнатуре вычисляется один раз при выполнении def, поэтому два вызова broken(1)и broken(2) вернут один и тот же список[1, 2]с одинаковымid.

**Фактический результат:**

```text

Оба вызова вернули ОДИН и тот же объект: id = 140092373281664 140092373281664
Исправленная функция: -> [1] | -> [2]
С переданным списком: [10] -> вернулось [10, 3]
```

Прогноз подтвердился. **Жизненный цикл объекта по умолчанию:** выражение[]вычисляется **один раз — в момент выполненияdef`**, а не при каждом вызове. Созданный список сохраняется в__defaults__функции и живёт, пока живёт сама функция. Каждый вызов без аргумента получает **тот же объект**;appendмутирует его, и мутация видна всем последующим вызовам. Первый вызов вернул[1, 2], а не[1], — список уже содержал результат второго вызова, потому что это один объект.

**Исправление** — сентинел None + копия:

```python
def add_result(value, results=None):
    if results is None:
        return [value]                 # каждый раз НОВЫЙ список
    return [*results, value]           # копия, исходный не изменяется
```

Проверка:add_result(1) == [1],add_result(2) == [2], это разные объекты; переданный список[10]послеadd_result(3, [10])не изменился, вернулось[10, 3];add_result.__defaults__ == (None,)`.


Прогноз подтвердился. Фабрика возвращает вложеннуюchecker(value), которая захватывает threshold в замыкании: проверено assert-ами, что passed_60.__closure__[0].cell_contents == 60, аpassed_85.__closure__[0].cell_contents == 85. У каждого замыкания своя ячейка — они не «делят» переменную.

### Декомпозиция и сложность

Программа разложена по смыслу: примитивы (mean/minimum/maximum) → классификация (classify) → агрегация одного студента (student_summary) → агрегация группы (group_summary,find_top_students,build_ranking) → презентация (format_report). Каждая функция делает одно дело, имеет явный контракт и тестируется отдельно;mainтолько связывает их.

Пусть S— число студентов, G— общее число оценок:

| Этап | Сложность |
|---|---|
| Всеstudent_summary|O(G)|
| Сбор всех оценок иoverall_mean|O(G)|
|find_top_students|O(G)|
|build_ranking(вставки) |O(S²)сравнений +O(G)на средние |
|format_report|O(S)|
| **Итогоgroup_summary`** | **`O(G + S²)времени,O(G + S)памяти** |

При типичном S ≪ G доминирует O(G). Рейтинг вставкамиO(S²) выбран сознательно:sorted() запрещён заданием там, где требуется собственный алгоритм; для больших S его заменили бы наO(S log S).
